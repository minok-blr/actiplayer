ACTIPLAYER · STORE-READY REDESIGN · ANDROID
Music that follows your body. Zero taps mid-activity.
Assumptions from the brief: Android only, evolving the existing Kotlin/Compose app; sources = local files + Spotify (App Remote, falls back to local); activities = Ski/Snowboard, Cycling, Running, Strength, HIIT, Generic; HR always optional; dark only; metric; 3 tabs (Home / Music / History); full setup wizard; Free + Pro with 7-day trial (Pro = Spotify, extra activities, AI section-seek v2). Kept the repo's exact mode hues (RIDING #FF5A1F / LIFT #4FC3F7 / PAUSED #7E8AA0 on #0B0E14) as the brand: mode color is the message. Type: Instrument Sans for UI, JetBrains Mono for telemetry. Every in-session target ≥ 64 dp (gloves).
Compare with the current UI. Architecture + build plan for the implementation model: ActiPlayer Plan.md.
